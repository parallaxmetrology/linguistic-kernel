# Roadmap

- **Out-of-sample collapse test:** gather labeled truncations from models and prompts the detector never saw.
- **Browser port** (JavaScript or Pyodide) so the demo can measure pasted text.
- **Weighted distance:** test whether a weighted or learned combination of axes beats word count as an anomaly signal. The unweighted one doesn't yet.
- **Length-adjusted readings:** report axes relative to what's typical at a given length.
- **Other languages:** word lists beyond English.
- **Conversational drift:** an agent skill that watches a long conversation for structural drift (accommodation, compression, frame capture), released once it's been tested.
